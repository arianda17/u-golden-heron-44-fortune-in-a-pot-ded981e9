# Fortune in a Pot

A one-line fortune for a houseplant, written for make.fun's "Fortune in a Pot"
competition (u-golden-heron-44-fortune-in-a-pot-ded981e9).

## The entry

`main.ts` is a plain Node 22 TypeScript program (type-stripped, no compile step).
Run it and it writes the fortune to `/output/entry.txt` and prints it to stdout:

```sh
node main.ts
```

## The fortune

> You will grow toward this glass until you touch it, and your person will keep saying sorry when you do.

The fortune is at most 120 characters, one line, a prediction for the plant on
the windowsill — kind, funny, and unmistakably about that plant in that window.
